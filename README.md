# 7-CFD-DEM-LPBF-Molten-Pool-Splatter

本代码是关于采用CFD-DEM计算LPBF成形过程熔池与金属颗粒的耦合行为。

（1）“计算文件.rar”文件：CFD-DEM计算算例（P=200W、V=1m/s、粉床厚度30微米），基于CFDEM®coupling-PUBLIC开源代码。

（2）“interface+particle.avi”文件：计算结果（熔池界面+金属颗粒）。

（3）“interface.avi”文件：计算结果（熔池界面）。

（4）“particle.avi”文件：计算结果（金属颗粒）。

（5）“2026 基于计算流体力学-离散单元法的激光粉末床熔融过程中熔池-飞溅耦合动力学行为.pdf”文件：已发表的学术论文。

论文引用格式：曹流, 姚权鸿. 基于计算流体力学-离散单元法的激光粉末床熔融过程中熔池-飞溅耦合动力学行为[J]. 金属学报, 2026, DOI:10.11900/0412.1961.2025.00343


This code is about using CFD-DEM to calculate the coupling behavior between the melt pool and metal particles during the LPBF forming process.

(1) "计算文件.rar" file: A CFD-DEM computational case (P=200 W, V=1 m/s, powder bed thickness 30 μm), based on the CFDEM®coupling-PUBLIC open-source code.

(2) "interface+particle.avi" file: Computational results (melt pool interface + metal particles).

(3) "interface.avi" file: Computational results (melt pool interface).

(4) "particle.avi" file: Computational results (metal particles).

(5) "2026 基于计算流体力学-离散单元法的激光粉末床熔融过程中熔池-飞溅耦合动力学行为.pdf" file: A published academic paper.

Paper citation format: Liu Cao, Quanhong Yao. Coupled Dynamic Behavior of Molten Pool-Spatter During Laser Powder Bed Fusion Based on Computational Fluid Dynamics-Discrete Element Method[J]. Acta Metallurgica Sinica, 2026, DOI:10.11900/0412.1961.2025.00343
